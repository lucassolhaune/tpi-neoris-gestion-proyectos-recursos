# Indicadores de control y estándares de desempeño

| Indicador | Cómo se mide | Estándar | Frecuencia / responsable |
|---|---|---|---|
| Tiempo de respuesta | Percentil 95 de consultas de disponibilidad | < 2 s con 500 usuarios concurrentes | Pruebas de carga y mensual / QA |
| Capacidad de registros | Registros de horas por mes y perfiles activos | 50.000 registros/mes y 4.000 perfiles, degradación < 10 % | Trimestral / DevOps |
| Cumplimiento del cronograma | Semanas de desvío respecto del Gantt | ≤ 1 semana por tarea; fin en la semana 24 como máximo | Semanal / Líder de proyecto y PMO |
| Horas facturadas sin aprobar | Registros facturados sin pasar por *aprobado* | 0 | Cada cierre / Finanzas |
| Duplicados de facturación | Registros con más de un comprobante | 0 | Cada cierre / Finanzas |
| Utilización | Horas facturables ÷ horas disponibles | 85 % (valor de referencia propuesto) | Mensual / Delivery |
| Tiempo de conciliación | Reducción frente al proceso manual | −30 % en 3 meses | Mensual / Finanzas |
| Defectos críticos abiertos | Defectos críticos sin resolver | 0 antes del despliegue | Antes de implementar / QA |
